# Music App · Android Design System

AI-ready design system for an Android music app, refactored from an imperfect Figma DS and 7 app screenshots (Brownfield, Scenario C).

- **Storybook (live docs):** https://abdulsalahuddin94-dev.github.io/music-app-android-design-system/
- **Figma:** [Brownfield DS](https://www.figma.com/design/igARrYUXQ2K2nGvQPKKhXl/Brownfield-DS) (library) and [Brownfield Design](https://www.figma.com/design/ev280FjNRmVhoCAvnnHfqT/Brownfield-Design) (Listen flow, 6 screens, Light and Dark)
- **For coding agents:** `DESIGN.md` and `AGENTS.md`
- **Skills:** `Foundation_Skill/` and `Component_Skills/` (Form Elements, Navigation, Data Display)
- **Data:** `data/tokens.json` (255 variables), `data/component-registry.json` (40 components), `data/rules.json`, `data/screen-templates.json`
- **History:** `CHANGELOG.md`, `docs/decisions.md`, `audits/`

Run the Storybook locally: `npm --prefix storybook install` then `npm --prefix storybook run storybook` (http://localhost:6009).
